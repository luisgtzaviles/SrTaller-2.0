# Eventos candidatos del Future State de recepción

**Estado:** `Proposed`.
**Propósito:** Definir hechos futuros candidatos en pasado, sin convertirlos en contratos técnicos ni eventos canónicos aprobados.
**Alcance:** Pre-recepción, identidad, custodia, condición, consentimiento, acceso, orden, comprobante, evidencia y cierre de recepción.
**Fuente:** Future State Big Picture, Current State Event Storming, auditorías legacy y eventos canónicos no aprobados.
**Audiencia:** Product Owner, Operaciones, Seguridad, Legal y Arquitectura.
**Última actualización:** 2026-07-14.

## Convención

El nombre inglés está en pasado y expresa un hecho de negocio candidato. “Sistema” significa que el hecho depende de una confirmación del proceso; no impone publicación, mensajería ni arquitectura orientada a eventos.

## Clasificación por naturaleza

| Naturaleza | Eventos |
|---|---|
| Negocio | `FSR-EVENT-001` a `010`, `019`, `024`, `025` |
| Evidencia | `FSR-EVENT-012`, `022`, `023` |
| Custodia | `FSR-EVENT-009` a `013` |
| Consentimiento y seguridad | `FSR-EVENT-014` a `018` |
| Sistema/documento | `FSR-EVENT-019` a `021` |

La clasificación se superpone cuando un hecho tiene significado de custodia y evidencia; no define bounded contexts.

## Actividades que no deberían modelarse como evento de negocio

| Actividad | Motivo | Estado |
|---|---|---|
| Hacer clic en “siguiente” | Interacción de UI sin hecho confirmado. | `Rejected` como evento de negocio |
| Abrir formulario o modal | Acción técnica sin cambio de responsabilidad. | `Rejected` como evento de negocio |
| Consultar el siguiente folio | Predicción no significa asignación. | `Rejected` como evento de negocio |
| Validar un campo localmente | Control técnico; sólo el resultado aceptado puede producir un hecho. | `Rejected` como evento de negocio |
| Generar una vista previa | No prueba emisión ni entrega del comprobante. | `Rejected` como evento de negocio |
| Subir bytes sin relación aceptada | No prueba evidencia utilizable. | `Rejected` como evento de negocio |
| Imprimir físicamente una hoja | Puede requerir auditoría operacional, pero no sustituye `ReceptionReceiptIssued`. | `Deferred` |
