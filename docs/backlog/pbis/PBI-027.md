# PBI-027 — Define and apply the R0 temporal model

## Estado

- **Estado:** Blocked.
- **Tipo:** R0 data/application foundation.
- **Owner:** Producto + Operaciones + Arquitectura + Ingeniería.
- **Riesgo:** alto.

## Objetivo

Resolver DEC-037/038 para conservar instantes autoritativos y presentar tiempo
operativo en la zona correcta sin perder historia.

## Alcance y exclusiones

Incluye autoridad tenant/sucursal, cambio de zona, almacenamiento, presentación
y pruebas de casos límite. Excluye calendarios, nómina, SLA comerciales y UI
final.

## Bloqueo

Producto aún debe decidir si la zona operativa pertenece al tenant o a la
sucursal y cómo se gobierna el cambio. No se inventa una default.

## Criterios de aceptación

- Autoridad y fallback de zona aprobados.
- Instante autoritativo y zona de presentación separados.
- Cambio no reescribe historia.
- Casos multisucursal y límites temporales son reproducibles.

## Evidencia y gates

Decisión de Producto, ADR/contrato temporal, matriz de casos y pruebas con reloj
controlado.

## Próxima revisión

Después de la decisión de Producto sobre DEC-037.
