# PBI-026 — Implement contextual capabilities and reinforced authorization

## Estado

- **Estado:** Draft.
- **Tipo:** R0 authorization/security foundation.
- **Owner:** Producto + Seguridad + Arquitectura + Ingeniería.
- **Riesgo:** crítico.

## Objetivo

Aplicar DEC-017–020 y ADR-012/013 mediante capacidades server-side,
deny-by-default, scopes tenant/sucursal y controles reforzados para acciones
sensibles de R0.

## Alcance y exclusiones

Incluye composición mínima por operación, unión de capacidades, revocación,
niveles 1–4, reautenticación/segundo aprobador cuando aplique y pruebas de
bypass. Excluye permisos de Reparaciones/R1, UI y roles personalizados no
requeridos.

## Dependencias

PBI-025, operaciones exactas de R0 y clasificación de sensibilidad. La
composición debe quedar dentro del refinamiento de este PBI antes de `Ready`.

## Criterios de aceptación

- Matriz actor/acción/recurso/scope y niveles 1–4 aprobada.
- Deny-by-default y servidor como autoridad.
- Roles de otro tenant y scope no asignado son rechazados.
- Revocación es efectiva y no hay bypass por ruta/payload/UI.
- Refuerzo de un solo uso conserva atribución y segregación.

## Evidencia y gates

Matriz, casos allow/deny/revoke, mutaciones, anti-enumeración, manifest y
checklist DEC063-C06.

## Próxima revisión

Después de PBI-025; completar composición y estimación para evaluar `Ready`.
