# PBI-034 — Operational Session

## Estado

- **Estado:** Blocked por PBI-024/PBI-025/PBI-032.
- **Tipo:** Identity / Security Foundation.
- **Owner:** Producto + Seguridad + Operaciones + Ingeniería.
- **Riesgo:** crítico.
- **Estimación:** TBD.
- **Sprint:** candidato posterior de Sprint 01; no autorizado.

## Objetivo

Mantener una identidad operacional atribuible dentro del contexto confiable de
una Station después de autenticar el PIN.

## Contrato aprobado

- Una sesión activa por Station.
- Un User puede operar en varias Stations si sus assignments lo permiten.
- Idle timeout de 60 minutos renovado sólo por actividad autenticada válida.
- Lifetime absoluto de 12 horas.
- Logout termina sesión, no Station binding.
- Cambiar usuario termina/reemplaza sesión y exige nuevo PIN.
- Reset/revoke de PIN o User invalida sus sesiones activas.

## Datos mínimos

`sessionId`, `tenantId`, `branchId`, `stationId`, `userId`, `issuedAt`,
`lastActivityAt`, `expiresAt` y estado.

## Fuera de alcance

Sesión administrativa de plataforma, SSO, recovery externo y autorización de
acciones. La sesión autentica; PBI-026 autoriza.

## Criterios

Expiración, cambio de usuario, revocación, replay, concurrencia y manipulación
de contexto fallan cerrados y tienen pruebas con reloj controlado.
