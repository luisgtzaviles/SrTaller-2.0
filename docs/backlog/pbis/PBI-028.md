# PBI-028 — Implement safe logging, business audit and observability baseline

## Estado

- **Estado:** Draft.
- **Tipo:** R0 operations/security foundation.
- **Owner:** Operaciones + Ingeniería + Seguridad + Arquitectura.
- **Riesgo:** alto.

## Objetivo

Aplicar DEC-045–048 y DEC-044 para correlacionar un recorrido de R0 con logs
seguros, auditoría de negocio separada, correlation ID y health/readiness
mínimos.

## Alcance y exclusiones

Incluye allowlist/redacción, evento autoritativo de auditoría, propagación de
correlación y señales mínimas con owner. Excluye proveedor, OpenTelemetry,
Sentry, Datadog, retención legal completa y dashboards definitivos.

## Dependencias

PBI-024/PBI-025, PBI-027 para timestamps operativos y PBI-029 para secretos.
DEC-044 gobierna categorías, envelope y sanitización.

## Criterios de aceptación

- Logs y auditoría tienen propósitos y stores conceptualmente separados.
- Tenant/sucursal/actor/estación/operación/correlación se registran cuando
  aplican, sin PIN/token/SQL/payload sensible.
- Correlation ID se genera/propaga de forma segura.
- Health/readiness distinguen configuración e infraestructura.
- Casos de redacción y ausencia de secretos pasan.

## Evidencia y gates

Catálogo de campos, eventos auditables, pruebas de redacción/correlación,
DEC044-C06/C08, DEC051-C05 y manifest.

## Próxima revisión

Refinar después de PBI-024/PBI-025/PBI-027/PBI-029.
